# Endpoint Detection & Investigation

> **Status:** draft — pending module design and Project Owner approval  
> **Module ID:** 03-endpoint-detection-investigation  
> **Curriculum version:** 0.1

## Purpose
Interpret Windows endpoint telemetry, especially Sysmon events, and investigate suspicious process, logon, file, and network activity.

## Target audience
Learners following the SOC-LAB program. Final entry level and prerequisites remain to be confirmed.

## Proposed learning outcomes
By the end of this module, learners should be able to:
- Interpret endpoint events
- build an activity timeline
- pivot across host evidence
- distinguish suspicious behavior from benign activity.

These outcomes are preliminary and require measurable criteria and mapping to lessons and assessments.
