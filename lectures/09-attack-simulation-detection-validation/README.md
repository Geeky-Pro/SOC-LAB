# Attack Simulation & Detection Validation

> **Status:** draft — pending module design and Project Owner approval  
> **Module ID:** 09-attack-simulation-detection-validation  
> **Curriculum version:** 0.1

## Purpose
Use controlled, authorized attack emulation to generate observable behaviors and assess whether telemetry, searches, and detections work as intended.

## Target audience
Learners following the SOC-LAB program. Final entry level and prerequisites remain to be confirmed.

## Proposed learning outcomes
By the end of this module, learners should be able to:
- Define safe simulation scope
- execute or interpret approved test cases in the isolated lab
- compare expected and observed telemetry
- evaluate detection gaps and document results.

These outcomes are preliminary and require measurable criteria and mapping to lessons and assessments.
