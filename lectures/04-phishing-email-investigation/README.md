# Phishing & Email Security Investigation

> **Status:** draft — pending module design and Project Owner approval  
> **Module ID:** 04-phishing-email-investigation  
> **Curriculum version:** 0.1

## Purpose
Investigate suspicious email reports, message headers, sender and URL indicators, attachments, and user impact using safe local artifacts and workflows.

## Target audience
Learners following the SOC-LAB program. Final entry level and prerequisites remain to be confirmed.

## Proposed learning outcomes
By the end of this module, learners should be able to:
- Inspect email headers and artifacts
- assess sender, links, and attachments safely
- weigh indicators
- produce a defensible verdict and user guidance.

These outcomes are preliminary and require measurable criteria and mapping to lessons and assessments.
