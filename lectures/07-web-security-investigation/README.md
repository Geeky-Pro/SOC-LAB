# Web Security Monitoring & Investigation

> **Status:** draft — pending module design and Project Owner approval  
> **Module ID:** 07-web-security-investigation  
> **Curriculum version:** 0.1

## Purpose
Investigate web server and application activity through access logs, request patterns, response codes, and correlated network/endpoint evidence.

## Target audience
Learners following the SOC-LAB program. Final entry level and prerequisites remain to be confirmed.

## Proposed learning outcomes
By the end of this module, learners should be able to:
- Analyze web access/application logs
- identify suspicious request patterns
- construct a request timeline
- correlate web activity with network and endpoint evidence.

These outcomes are preliminary and require measurable criteria and mapping to lessons and assessments.
