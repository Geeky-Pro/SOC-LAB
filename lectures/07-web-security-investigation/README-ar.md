# مراقبة أمن الويب والتحقيق فيه

> **الحالة:** مسودة — بانتظار تصميم الوحدة واعتماد مالك المشروع  
> **معرّف الوحدة:** 07-web-security-investigation  
> **إصدار المنهج:** 0.1

## الغرض

التحقيق في نشاط خادم الويب والتطبيق عبر سجلات الوصول وأنماط الطلبات ورموز الاستجابة والأدلة المترابطة من الشبكة والأجهزة الطرفية.

## الجمهور المستهدف

متعلمو برنامج SOC-LAB. لا يزال مستوى الدخول النهائي والمتطلبات السابقة بانتظار التأكيد.

## مخرجات التعلم المقترحة

بنهاية هذه الوحدة، ينبغي أن يتمكن المتعلمون من تحليل سجلات الوصول/التطبيق على الويب، وتحديد أنماط الطلبات المريبة، وبناء خط زمني للطلبات، وربط نشاط الويب بأدلة الشبكة والأجهزة الطرفية.

هذه المخرجات أولية وتحتاج إلى معايير قابلة للقياس ومواءمة مع الدروس والتقييمات.
