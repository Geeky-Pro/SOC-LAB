## Purpose
Explain network IDS/IPS concepts, interpret Suricata alerts, and validate detection context and limitations.

## Target audience
Learners following the SOC-LAB program. Final entry level and prerequisites remain to be confirmed.

## Proposed learning outcomes
By the end of this module, learners should be able to:
- Interpret Suricata alerts and metadata
- investigate supporting packet/context evidence
- explain detection limitations and false positives
- document validation results.

These outcomes are preliminary and require measurable criteria and mapping to lessons and assessments.
