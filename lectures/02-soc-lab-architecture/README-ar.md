# معمارية مختبر SOC ونشره

> **الحالة:** مسودة — بانتظار تصميم الوحدة والتحقق العملي واعتماد مالك المشروع  
> **معرّف الوحدة:** 02-soc-lab-architecture  
> **إصدار المنهج:** 0.1

## الغرض

تعليم المتعلمين فهم بيئة SOC-LAB المعزولة ونشرها والتحقق منها، بما يشمل مناطق الثقة والآلات الافتراضية ومسارات الشبكة ومصادر القياس وتدفق بيانات SIEM.

## مخرجات التعلم الأولية

ينبغي أن يتمكن المتعلمون من:

- شرح البنية وحدود الثقة ودور كل مكون.
- مواءمة الشبكات الافتراضية في VMware مع واجهات pfSense والمناطق الأمنية.
- نشر الآلات الافتراضية المطلوبة أو التحقق منها باستخدام بيان بناء موثق.
- تطبيق قواعد جدار ناري بين المناطق وفق أقل صلاحية واختبارها.
- التحقق من إدخال قياس الطرفيات والجدار الناري/IDS والويب إلى Splunk Enterprise.
- تشخيص مشكلات الشبكة والجمع والموارد الشائعة.
- التقاط أدلة تحقق منقحة واستعادة خط أساس نظيف.

تتطلب هذه المخرجات معايير تقييم قابلة للقياس قبل الإصدار.

## خط أساس المعمارية

- VMware Workstation؛ مختبر معزول واحد لكل طالب.
- Splunk Enterprise فقط للتنفيذ الحالي.
- pfSense مع Suricata مدمجة كحزمة؛ دون آلة Suricata منفصلة.
- Windows 10/11 مع Sysmon.
- Ubuntu Server في DMZ مخصصة.
- Kali Linux على `10.0.90.0/24`.
- تستخدم بقية مقاطع المختبر خطة العناوين المقترحة `10.0.0.0` الموثقة في `lab-environment/`.

## الموضوعات وتسلسل التدريس

يُطوّر المحتوى انطلاقاً من وثائق المعمارية: الافتراضية وشبكات الآلات؛ والتقسيم ومناطق الثقة؛ وتصميم واجهات وقواعد pfSense؛ وموضع SIEM؛ وجمع القياس؛ والتحقق واستكشاف الأعطال؛ ولقطات خط الأساس والتعافي.

## الأنشطة العملية

تُعد باستخدام قالب المختبر المعتمد بعد التحقق من إصدارات البرامج ونشر مرجعي نظيف.
