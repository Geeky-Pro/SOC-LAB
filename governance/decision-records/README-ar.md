# سجلات قرارات المعمارية

استخدم سجل قرار معمارية (ADR) للقرارات التي تؤثر جوهرياً في بنية المستودع أو حدود المنهج أو معمارية المختبر أو سير عمل الذكاء الاصطناعي أو الصيانة طويلة الأجل.

## التنسيق المقترح

- **الحالة:** مقترح أو مقبول أو مستبدل أو متقاعد.
- **التاريخ:** تاريخ القرار.
- **السياق:** المشكلة والقيود.
- **القرار:** الخيار المحدد.
- **البدائل:** الخيارات التي نوقشت.
- **العواقب:** المفاضلات وأعمال المتابعة.
- **المالك:** مالك المشروع أو صاحب صلاحية القرار.

تُضاف سجلات ADR دون محو التاريخ. استبدل قراراً قديماً بسجل جديد بدلاً من إعادة كتابة التاريخ بصمت.
