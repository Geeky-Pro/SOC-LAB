# دورة حياة المحتوى

## قيم الحالة

| الحالة | المعنى |
|---|---|
| `planned` | مقبول للتطوير مستقبلاً؛ لم تبدأ صياغة المحتوى بعد. |
| `draft` | العمل جارٍ؛ غير جاهز لاستخدام المتعلمين. |
| `in-review` | أُرسل للمراجعة المستقلة. |
| `approved` | راجعه مالك المشروع وقبله للاستخدام المقصود. |
| `released` | أُدرج في دورة أو مستودع منشور. |
| `deprecated` | محفوظ للرجوع إليه لكنه لم يعد موصى به للتقديم الحالي. |

## المسار المعتاد

`planned` ← `draft` ← `in-review` ← `approved` ← `released`

تعاد المسودة المرفوضة إلى `draft` مع نتائج مراجعة قابلة للتنفيذ. ويمكن تنقيح المحتوى المعتمد عبر دورة مراجعة جديدة.

## التحقق مستقل عن الحالة

لا تثبت حالة المحتوى تنفيذه عملياً. سجّل التحقق بصورة مستقلة:

- `NOT VALIDATED`: لا تتوفر أدلة تحقق عملي.
- `PASS`: اجتازت الفحوص المحددة مع وجود أدلة.
- `PASS WITH NOTES`: اجتازت الفحوص مع توثيق القيود.
- `NEEDS REVISION`: أخفق فحص مطلوب واحد أو أكثر.
- `BLOCKED`: تعذر إكمال التحقق بسبب تبعية أو مشكلة وصول.

## إمكانية التتبع المطلوبة

للمحتوى المهم، سجل المالك والمراجع وتاريخ المراجعة ومراجع المصادر والإصدارات المنطبقة وأدلة التحقق والقيود المعروفة.
