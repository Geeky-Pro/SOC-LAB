# معمارية المستودع

## أهداف المعمارية

يفصل المستودع الحوكمة والمنهج ووحدات التدريس والبنية التحتية المشتركة للمختبر وهندسة الكشف والاستجابة للحوادث والقوالب والأتمتة والتحقق والمحتوى التاريخي.

## مسؤوليات المسارات العليا

| المسار | المسؤولية |
|---|---|
| `.github/` | تعريفات الوكلاء والتعليمات والمطالبات وسير العمل وقوالب المشكلات الخاصة بـ GitHub. |
| `.agents/skills/` | مهارات الوكلاء القابلة لإعادة الاستخدام وفق بنية Agent Skills. |
| `governance/` | صلاحيات المشروع والسياسات والأدوار ومعايير الجودة وقرارات المعمارية. |
| `curriculum/` | مخرجات التعلم على مستوى البرنامج والخرائط والكفاءات والجدول وتصميم التقييم. |
| `lectures/` | حزم تعلم مستقلة للوحدات تشمل مواد المدرب والطالب والمختبرات والسيناريوهات والتقييمات. |
| `lab-environment/` | معمارية المختبر المشترك ونشره وإعداداته والتحقق والتعافي. |
| `detection-engineering/` | معايير الكشف المشتركة والقواعد والاستعلامات والمواءمات وأساليب التحقق. |
| `incident-response/` | إجراءات الاستجابة المشتركة ومعايير أدلة التشغيل. |
| `instructor/` | إرشادات التدريس والتقديم الصفي على مستوى البرنامج. |
| `templates/` | قوالب المحتوى المعتمدة القابلة لإعادة الاستخدام. |
| `tooling/` | النصوص البرمجية والمدققات والمولدات ومعالجة الأصول. |
| `tests/` | فحوص آلية للمستودع والوثائق والإعدادات والإصدارات. |
| `releases/` | ملاحظات الإصدارات وبياناتها الوصفية. |
| `Archive/` | مواد تاريخية محفوظة للمراجعة وإثبات المنشأ. |

## قواعد المواضع

- توضع البنية التحتية المشتركة في `lab-environment/`؛ وتوضع تمارين الوحدات في مجلد `labs/` الخاص بها.
- توضع أصول الكشف المشتركة في `detection-engineering/`؛ وتوضع كشوف الوحدات داخل الوحدة.
- توضع إجراءات الاستجابة العامة في `incident-response/`؛ وتبقى مهام الاستجابة الخاصة بالسيناريو مع السيناريو.
- توضع إرشادات التدريس على مستوى البرنامج في `instructor/`؛ وملاحظات تقديم الوحدة في مجلد `instructor/` الخاص بها.
- توضع القوالب المعتمدة في `templates/`. ويمكن للمهارات الإشارة إلى القوالب، لكن ينبغي ألا تحتفظ بنسخ متعارضة.
- لا تنشئ مجلدات فارغة أو ملفات افتراضية لمجرد استكمال شكل الشجرة.

## بنية الوحدة

راجع [معمارية الوحدات](module-architecture-ar.md). لا تحتوي الوحدة إلا على المجلدات الفرعية اللازمة لحزمة تعلمها الفعلية.


## معمارية المحتوى ثنائي اللغة

العربية والإنجليزية لغتان أساسيتان للمحتوى، وتُحفظ وثائقهما كملفات متقابلة داخل بنية المستودع نفسها. لا ننشئ شجرتين منفصلتين لكل لغة.

- تحتفظ النسخة الإنجليزية باسم الملف الأساسي.
- يضاف `-ar` إلى اسم الملف العربي قبل الامتداد، مثل `lesson-plan.md` و`lesson-plan-ar.md`.
- يوضع الملفان في المجلد نفسه.
- تبقى المعرفات المشتركة والأصول القابلة للمعالجة آلياً محايدة لغوياً قدر الإمكان.
- يجب أن يربط كل مستند جوهري بنسخته المقابلة.
- تُحدّث النسختان معاً أو توضح حالة الترجمة المعلقة.
- حالة الترجمة ومراجعة المحتوى والتحقق العملي حالات مستقلة.

راجع `governance/policies/bilingual-content-policy-ar.md` للقواعد التفصيلية.
