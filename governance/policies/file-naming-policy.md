# File and Directory Naming Policy

- Use lowercase English `kebab-case` for new paths and filenames.
- Use descriptive names that communicate purpose.
- Avoid spaces, unexplained abbreviations, and unstable lesson numbering in shared assets.
- Preserve original names inside `Archive/` unless a specific migration requires otherwise.
- Use conventional filenames when required by tooling, such as `README.md`, `AGENTS.md`, and `SKILL.md`.
- Keep language variants explicit and consistent, for example `student-guide.md` and `student-guide-ar.md`.
