# Repository Security Policy

- Never commit passwords, tokens, private keys, license secrets, or production credentials.
- Use clearly marked placeholders and safe example values.
- Do not include real student personal information or sensitive operational logs.
- Review scripts and configuration files before committing.
- Keep VM images, disk files, and large packet captures outside Git unless a specific, approved distribution method exists.
- Report exposed secrets promptly and rotate them; deleting a secret from the latest commit alone does not make it safe.
