# تصنيف الحوادث وشدتها

> **الحالة:** مسودة — نموذج تعليمي مقترح  
> **التحقق:** لم يتم التحقق

## 1. الغرض

يصف التصنيف طبيعة النشاط المشتبه به. أما الشدة فترتب الاستجابة حسب الأثر المحتمل أو الفعلي والاستعجال. يرتبط المفهومان لكنهما غير قابلين للاستبدال؛ فالفئة وحدها لا تحدد الشدة.

## 2. فئات تعليمية مقترحة

استخدم فئة أساسية واحدة ووسوماً ثانوية اختيارية. الفئات وصفية وليست متنافية.

| الفئة | أمثلة على النشاط محل التحقيق |
|---|---|
| برمجيات خبيثة / تنفيذ مريب | ملف تنفيذي أو برنامج نصي غير متوقع أو مؤشر استمرارية أو حمولة خبيثة |
| وصول غير مصرح به / اختراق حساب | مصادقة مشبوهة أو استخدام امتياز غير متوقع أو مؤشرات استيلاء على حساب |
| كشف بيانات / إخراجها | نقل غير متوقع أو كشف عام أو وصول غير مصرح به إلى بيانات حساسة |
| تسلل شبكي / قيادة وتحكم | وصول وارد مشبوه أو حركة شبيهة بالاتصال الدوري أو تحكم بعيد غير مصرح به |
| اختراق تطبيق ويب / خادم | مؤشرات استغلال أو اشتباه بصدفة ويب أو تغييرات غير مصرح بها في المحتوى أو العمليات |
| تصيد / هندسة اجتماعية | رسالة خبيثة أو جمع بيانات اعتماد أو تفاعل مستخدم مع طُعم |
| حجب خدمة / توافر | استنزاف موارد أو تعطيل يؤثر في توافر الخدمة |
| مسألة سياسة / مرتبطة بتهديد داخلي | اشتباه إساءة استخدام وصول مصرح به أو مخالفة سياسة أمنية |

لا تصنف نشاطاً على أنه إساءة داخلية أو خرق بيانات أو إصابة ببرمجية خبيثة دون أدلة كافية.

## 3. أبعاد الشدة

قيّم وسجل الأبعاد التالية:

- **الأثر:** عواقب السرية والسلامة والتوافر والأمن والعمليات.
- **النطاق:** عدد الأصول والهويات والخدمات والمواقع المتأثرة وأهميتها.
- **حساسية البيانات:** احتمال تأثر بيانات خاضعة للتنظيم أو سرية أو شخصية أو حرجة للأعمال.
- **التعرض والانتشار:** إمكانية الوصول الخارجي أو الحركة الجانبية أو الاستمرارية أو استمرار الوصول.
- **الاستعجال:** استغلال نشط أو إخراج مستمر أو سلوك تدميري أو أثر أعمال حساس للوقت.
- **الثقة:** جودة الأدلة وتعضيدها؛ يجب عدم إخفاء عدم اليقين.
- **قابلية التعافي:** توفر نسخ احتياطية موثوقة وخدمات بديلة وخيارات استعادة.

قد يتطلب احتمال أثر كبير مع ثقة منخفضة تحقيقاً عاجلاً؛ فضعف الثقة ليس مبرراً لتجاهل ضرر جسيم محتمل.

## 4. مقياس شدة SOC-LAB المقترح

هذا المقياس لترتيب الأولوية في الصف فقط؛ وليس اتفاقية مستوى خدمة إنتاجية أو معياراً عالمياً.

| المستوى | التفسير التعليمي | المعالجة المعتادة |
|---|---|---|
| **P1 — حرج** | دليل موثوق على أثر جسيم أو مستمر أو تعطيل خدمة حرجة أو اختراق واسع أو نشاط تدميري أو كشف بيانات عالي المخاطر | تصعيد فوري إلى المدرب/قائد الحادث؛ وتنسيق متواصل أثناء التمرين |
| **P2 — مرتفع** | اختراق أو كشف كبير يؤثر في أصول مهمة أو هويات ذات امتياز أو أنظمة متعددة؛ مع بقاء خطر جوهري نشط | تحقيق عاجل وقرار بشأن الاحتواء |
| **P3 — متوسط** | اختراق مشتبه به محدود النطاق أو نشاط مشبوه ذو أثر معروف محدود ودون دليل على انتشار واسع | تحقيق ذو أولوية مع نقاط تحقق محددة للتحديث |
| **P4 — منخفض** | نشاط منخفض الأثر أو محتوى أو ضعيف التعضيد ويتطلب توثيقاً أو متابعة اعتيادية | يوضع في قائمة المراجعة؛ وتحفظ المبررات ويعاد التقييم عند ظهور أدلة جديدة |

## 5. طريقة اتخاذ القرار

1. سجل الحقائق والمجهولات.
2. حدد الأصول والهويات والخدمات والبيانات المتأثرة.
3. قيّم كل بُعد من أبعاد الشدة.
4. أسند مستوى أولياً مع مبرر موجز.
5. حدد الأدلة التي قد ترفع التقييم أو تخفضه.
6. صعّد وفق عدم اليقين والأثر وقواعد الصلاحية المحلية.
7. أعد التقييم عند ورود دليل جوهري أو معلومات أثر جديدة.

الشدة متغيرة. سجل التغييرات وأوقاتها وأسبابها؛ ولا تستبدل التقييم الأولي بصمت.

## 6. الحد الأدنى لسجل التصنيف

- معرّف الحادث وحالته
- الفئة الأساسية والوسوم الثانوية
- الشدة الأولية ومبرراتها
- الأصول أو الهويات أو الخدمات المتأثرة
- الأثر المعروف أو المشتبه به على البيانات
- النشاط والتعرض الحاليان
- الثقة بالأدلة والفجوات
- صاحب القرار وموعد المراجعة التالية
