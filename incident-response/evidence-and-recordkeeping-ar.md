# الأدلة وحفظ سجلات الحوادث

> **الحالة:** مسودة  
> **التحقق:** لم يتم التحقق

## 1. الغرض والحدود

تحدد هذه الوثيقة الحد الأدنى لحفظ السجلات التشغيلية في تحقيقات SOC-LAB. وهي ليست إجراءً للأدلة الجنائية الرقمية أو أدلة الذاكرة، ولا تجيز جمع بيانات شخصية أو مقيدة.

## 2. مبادئ التعامل مع الأدلة

- اجمع ما هو مصرح به وذو صلة ومتناسب مع التمرين أو الحادث فقط.
- احفظ السجلات الأصلية حيثما أمكن؛ وحلل نسخاً أو صادرات.
- لا تغير الأدلة المصدرية أو تحذفها أو تعيد تسميتها أو تستبدلها.
- سجل من جمع العنصر أو تعامل معه ومتى ومن أين وكيف.
- استخدم طوابع زمنية متسقة وسجل المنطقة الزمنية وعدم يقين الساعة صراحةً.
- قيّد الوصول إلى الأدلة وتجنب وضع المواد الحساسة في مستودعات عامة أو قنوات غير معتمدة.
- سجل فحوص السلامة (مثل بصمة تشفيرية) عندما يدعمها سير العمل والأدوات؛ ولا تدّعِ التحقق من السلامة إن لم يُنفذ.
- احفظ مصدر الدليل: النظام المصدر والاستعلام أو المرشح وطريقة التصدير والنطاق الزمني والإعداد ذي الصلة.
- صعّد المسائل القانونية أو المتعلقة بالخصوصية أو التنظيم المشتبه بها إلى الجهة المعينة.

## 3. حقول سجل الأدلة

| الحقل | الوصف |
|---|---|
| معرّف الدليل | مرجع فريد ضمن الحادث |
| الوصف | ما يمثله العنصر |
| المصدر | مضيف أو مصدر سجل أو حساس شبكة أو تطبيق أو مبلّغ |
| وقت الجمع | طابع زمني مع المنطقة الزمنية |
| نطاق وقت الحدث | الفترة الزمنية التي تمثلها البيانات |
| الجامع | الشخص أو الدور الذي جمع العنصر |
| الطريقة | استعلام أو تصدير أو التقاط أو طريقة أخرى مصرح بها |
| الموقع الأصلي/المرجعي | موقع مضبوط أو مرجع نظام؛ لا تستخدم رابطاً عاماً يحوي أسراراً |
| السلامة | طريقة البصمة/التحقق والنتيجة، إن نُفذت فعلاً |
| سجل التعامل | النقل والوصول والتحويلات ونسخ التحليل |
| القيود | حقول مفقودة أو انحراف ساعة أو اقتطاع أو فجوات احتفاظ أو عدم يقين |

## 4. الخط الزمني للحادث

احتفظ بسجل زمني يتضمن:

- الأحداث المرصودة ومعرّفات الأدلة الداعمة؛
- إجراءات المحلل واستعلاماته؛
- القرارات والموافقات؛
- إجراءات الاحتواء والمعالجة والتعافي؛
- الاتصالات والتصعيدات؛
- تغييرات الحالة والشدة.

ميّز وقت وقوع الحدث عن وقت اكتشافه أو جمعه أو الإبلاغ عنه.

## 5. مصادر أدلة SOC-LAB

قد تشمل المصادر أحداث Windows/Sysmon ونتائج بحث Splunk وسجلات pfSense وSuricata وملفات PCAP وسجلات ويب Ubuntu ورسائل Mailpit. يعتمد توفرها على إعداد المختبر الفعلي. تحقق من جاهزية المصدر ووثق القياس الناقص بدلاً من افتراض وجوده.

استخدم أدلة اصطناعية أو منقحة في المواد التعليمية. لا تودع بيانات اعتماد حقيقية أو رموز وصول أو بيانات شخصية أو بيانات غير مرخصة أو التقاطات خام كبيرة. خزّن أدلة المختبر في مواقع معتمدة فقط واتبع سياسات أمن المستودع والتعامل مع البيانات.

## 6. إعداد التقارير والاحتفاظ

يحدد قائد الحادث الموقع المعتمد للسجلات وضوابط الوصول والاحتفاظ والمشاركة. هذه التفاصيل خاصة بكل مؤسسة، ولا يجوز للمتعلم اختلاقها. في تمارين الصف استخدم مساحة العمل التي يحددها المدرب واحذف البيانات المنشأة أثناء التنظيف عند الاقتضاء.
