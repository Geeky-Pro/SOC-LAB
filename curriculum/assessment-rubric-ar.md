# مقياس تقييم SOC-LAB

> **الحالة:** مسودة — أوصاف أداء مشتركة لتقييم الوحدات والمشروع الختامي.  
> **السلطة:** يلزم اعتماد مالك المشروع قبل الاستخدام التشغيلي.  
> **سياسة الدرجات:** لا تُفترض أوزان أو حدود نجاح أو فواصل درجات.

## مستويات الأداء

| المستوى | الوصف |
|---|---|
| 4 — متقدم | دقيق ومكتمل، يستند إلى استدلال مستقل، قابل لإعادة الإنتاج، ويبين القيود بوضوح. |
| 3 — متمكن | يحقق المخرج باستدلال سليم، مع نواقص طفيفة لا تغير الاستنتاج. |
| 2 — نامٍ | فهم جزئي؛ نواقص جوهرية أو تعزيز ضعيف أو حاجة إلى توجيه المدرب. |
| 1 — غير كافٍ | غير مسنود أو غير دقيق جوهرياً أو غير آمن أو غير مكتمل أو يتعذر إعادة إنتاجه من الأدلة المسلّمة. |
| غير مرصود | لم تُمكّن المهمة من ملاحظة هذا المعيار بصورة منصفة؛ يطبق فقط وفق قاعدة تقييم منشورة. |

## المعايير المشتركة

| المعيار | متقدم (4) | متمكن (3) | نامٍ (2) | غير كافٍ (1) |
|---|---|---|---|---|
| النطاق والسلامة | يحدد الأصول المصرح بها والفترة والحدود وشروط الإيقاف أو التراجع؛ ويلتزم بها | النطاق واضح والضوابط متبعة | غموض طفيف أو حاجة إلى توجيه | يتجاوز النطاق أو يتجاهل الضوابط أو يتصرف دون تصريح |
| مصدر الأدلة | يمكن تتبع كل ادعاء جوهري إلى مصدر أو عنصر وطابع زمني أو موضع ذي صلة | يمكن تتبع معظم الادعاءات مع فجوات طفيفة | تفتقر ادعاءات متعددة إلى مراجع دقيقة | يتعذر العثور على الأدلة أو تمثيل مصدرها بصورة مضللة |
| التفسير التقني | يفسر الحقول أو البروتوكولات أو السلوكيات ذات الصلة تفسيراً صحيحاً ويشرح الحدود | التفسير الأساسي صحيح مع نواقص طفيفة | تفسير جزئي أو تعميم مفرط | تفسير غير صحيح جوهرياً أو غير مسنود |
| اختبار الفرضيات | يختبر التفسيرات المتنافسة ويسجل الأدلة المؤيدة والمعارضة | يختبر فرضية معقولة ويراعي البدائل | اختبار محدود | يعرض التخمين كاستنتاج أو يتجاهل التناقضات |
| الربط والخط الزمني | يوحد الوقت ويربط الكيانات عبر المصادر ويشرح عدم اليقين ومشكلات الساعات | الخط الزمني والروابط الأساسية سليمة في معظمها | فجوات أو ضعف الربط بين المصادر | خط زمني مضلل أو ربط غير مسنود |
| ترتيب الأولويات والاستجابة | يقترح إجراءات متناسبة ضمن الصلاحية مع بيان الأثر والتراجع والتحقق | توصية معقولة ضمن الصلاحية | يغفل مفاضلات أو تحققاً جوهرياً | توصية غير آمنة أو غير مصرح بها |
| التواصل والسجلات | تقرير واضح وملائم للجمهور يفصل الوقائع والفرضيات والمجهولات والقرارات | تقرير واضح مع نواقص طفيفة | صعب المتابعة أو يخلط الوقائع بالافتراضات | مضلل أو غير مكتمل |
| التحقق والقيود | يميز بين التنفيذ والقياس عن بُعد والتحليل والكشف والتنبيه والمنع وحالات التحقق | يميز معظم الحالات والقيود | ادعاءات التحقق ملتبسة | يدعي التنفيذ أو التغطية بلا دليل |

## الحد الأدنى للأدلة

بحسب الصلة، تحدد التسليمات معرّف التقييم وتاريخه والبيئة أو مجموعة البيانات والنطاق المصرح به ومراجع المصدر أو العنصر والطوابع الزمنية والمنطقة الزمنية والوقائع الملحوظة والفرضيات والبدائل والمجهولات والاستدلال والثقة والإجراء المقترح والصلاحية والأثر والتراجع والتحقق، وما إذا كانت الأدلة ملتقطة أو اصطناعية أو محاكاة أو استنتاجية أو متحققاً منها وقت التشغيل.

## استخدام التقييم

- اربط المعايير بالمخرجات التي يجري تقييمها تحديداً؛ ولا تحتسب معايير غير ذات صلة.
- حدد المخرجات الفردية والجماعية؛ فأدلة الفريق وحدها لا تثبت كفاءة الفرد.
- زوّد الطلاب بموجز التقييم والموارد المسموح بها والوقت وصيغة التسليم والمقياس قبل التقييم.
- أبقِ مفاتيح المدرب منفصلة عن مواد الطلاب.
- يقرر مالك المشروع الأوزان وحد النجاح وإعادة الاختبار والمعالجة والتيسيرات والاحتفاظ بالأدلة.
