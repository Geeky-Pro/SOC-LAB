# ملف دخول المتعلم وقائمة الجاهزية

> **الحالة:** مقترح مسودة — بانتظار تأكيد مالك المشروع.  
> **الغرض:** تحديد نقطة بداية عادلة للبرنامج المقترح ومدته 89 ساعة؛ وهذا تشخيص وليس اختبار شهادة أو استبعاد.

## ملف الدخول المقترح

يحتاج المتعلمون إلى إلمام عام بالحاسوب واستعداد لاستخدام واجهات Windows وLinux. لا تُشترط خبرة سابقة في SOC أو شهادات أمنية أو برمجة متقدمة أو خبرة مهنية في الاستجابة للحوادث.

## قائمة التشخيص

| المجال | الحد الأدنى الملحوظ | دليل التشخيص | المعالجة |
|---|---|---|---|
| التعامل مع الحاسوب والملفات | إنشاء مجلدات، واستخراج أرشيفات، وتحديد امتدادات الملفات، واستخدام متصفح، والتقاط صورة شاشة | مهمة قصيرة لإدارة الملفات | توجيه لاستخدام محطة العمل |
| الشبكات | شرح IP والشبكة الفرعية والبوابة وDNS وTCP/UDP والعميل/الخادم | تسمية عناصر مخطط شبكة وتفسير ناتج `ipconfig` أو `ip a` | مدخل إلى الشبكات |
| Windows | التنقل في عارض الأحداث، وتحديد عملية، وفحص الخدمات/إدارة المهام، وتشغيل أمر أساسي | العثور على حدث مقدم وتحديد مصدره ووقته | مدخل إلى إدارة Windows |
| Linux | التنقل بين المجلدات وقراءة سجل نصي وتشغيل أوامر shell أساسية | فحص سجل نموذجي باستخدام `pwd` و`ls` و`cd` و`cat`/`less` | مدخل إلى سطر أوامر Linux |
| الويب والبريد الإلكتروني | تحديد أجزاء URL، وشرح DNS على مستوى عام، والتمييز بين المرسل الظاهر وحقول ترويسة الرسالة | تحليل URL نموذجي وحقول ترويسة بريد | مراجعة أساسيات الويب والبريد |
| الممارسة التحليلية | فصل الوقائع الملحوظة عن الافتراضات وتحديد الأدلة الناقصة | تمرين قصير لتنبيه ملتبس | درس مصغر في الاستدلال من الأدلة |
| التوثيق | تسجيل الطابع الزمني والمصدر والملاحظة والسؤال بوضوح | إكمال ملاحظة حالة قصيرة | شرح عملي للتوثيق |

## نتائج الجاهزية

- **جاهز:** أظهر خط الأساس أو أكمل المراجعة التأسيسية.
- **جاهز مع دعم:** يمكنه المتابعة مع دعم ومراجع موثقة.
- **يوصى بالمعالجة:** ينبغي سد فجوة تأسيسية قبل الوحدة العملية ذات الصلة.
- **لم يُقيّم:** لم تُجمع أدلة تشخيصية.

لا تستنتج الكفاءة من الإفادة الذاتية وحدها. استخدم النتائج لتخطيط الدعم، لا لتغيير المخرجات بصمت أو استبعاد المتعلمين.

## ضمانات التقديم

- نفّذ تشخيصاً قصيراً قبل الوحدة 01 أو خلالها.
- وفر فرص معالجة متكافئة.
- أعد التحقق من فجوات محددة فقط قبل الأعمال العملية ذات التبعيات العالية.
- أكد متطلبات الدفعة واحتياجات الإتاحة واللغة وقدرة الأجهزة وإيقاع التقديم مع مالك المشروع والمدرب.

## قرارات المالك

1. تأكيد ملاءمة ملف الدخول لهذه الدفعة.
2. تحديد ما إذا كانت مراجعات الشبكات وWindows وLinux تسبق الدورة أو تندرج ضمن الساعات التدريسية الـ89.
3. تأكيد ترتيبات التيسير والمعالجة.
4. تأكيد الحد الأدنى لمواصفات أجهزة الطلاب قبل الوحدة 02.
