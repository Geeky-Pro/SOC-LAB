# Learner Entry Profile & Readiness Checklist

> **Status:** draft proposal — pending Project Owner confirmation.
> **Purpose:** establish a fair starting point for the proposed 89-hour program; this is a diagnostic, not a certification or exclusion test.

## Proposed entry profile
Learners need general computer literacy and willingness to use Windows and Linux interfaces. Prior SOC employment, security certifications, advanced programming, and professional incident-response experience are not required.

## Diagnostic checklist
| Area | Minimum observable baseline | Diagnostic evidence | Remediation |
|---|---|---|---|
| Computer/file handling | Create folders, extract archives, identify extensions, use a browser, capture a screenshot | Short file-management task | Workstation orientation |
| Networking | Explain IP, subnet, gateway, DNS, TCP/UDP, client/server | Label a network diagram and interpret `ipconfig` or `ip a` output | Networking primer |
| Windows | Navigate Event Viewer, identify a process, inspect Services/Task Manager, run a basic command | Locate a provided event and identify source/time | Windows administration primer |
| Linux | Navigate directories, read a text log, run basic shell commands | Inspect a sample log using `pwd`, `ls`, `cd`, and `cat`/`less` | Linux CLI primer |
| Web/email | Identify URL components, explain DNS at a high level, distinguish visible sender from message headers | Parse sample URL and email header fields | Web/email fundamentals refresher |
| Analytical practice | Separate observed fact from assumption and identify missing evidence | Short ambiguous-alert exercise | Evidence reasoning mini-lesson |
| Documentation | Record timestamp, source, observation, and question clearly | Complete a short case note | Documentation walkthrough |

## Readiness outcomes
- **Ready:** baseline demonstrated or refresher completed.
- **Ready with support:** may proceed with documented support and references.
- **Remediation recommended:** foundational gap should be addressed before the related practical module.
- **Not assessed:** no diagnostic evidence collected.

Do not infer competence from self-report alone. Use results to plan support, not to silently change outcomes or exclude learners.

## Delivery safeguards
- Administer a short diagnostic before or during Module 01.
- Provide equivalent remediation opportunities.
- Recheck only specific gaps before high-dependency practical work.
- Confirm cohort prerequisites, accessibility/language needs, hardware capability, and delivery pace with the Project Owner and Instructor.
