# خريطة تبعيات المختبر

> **الحالة:** مسودة — تصف التبعيات المنطقية فقط؛ وليست سجلاً للتحقق من النشر.

## المكونات الأساسية

| المكون | الاستخدام التعليمي | الوحدات التابعة |
|---|---|---|
| VMware Workstation | آلات افتراضية معزولة ولقطات | 02–11 |
| pfSense | تقسيم الشبكة والتوجيه وقياس الجدار الناري عن بُعد | 02، 05، 06، 09–11 |
| Suricata مدمج في pfSense | تنبيهات كشف التسلل الشبكي | 06، 09–11 |
| Splunk Enterprise | البحث والتحقيق ولوحات المعلومات والربط | 02–11 |
| Windows مع Sysmon | قياس العمليات وتسجيل الدخول والملفات والشبكة عن بُعد | 03، 09–11 |
| Kali Linux | توليد حركة مرور مصرح بها ومحاكاة مضبوطة | 05–07، 09–11 |
| خادم ويب Ubuntu | خدمة الويب وسجلات الوصول والتطبيقات | 07، 09–11 |
| Mailpit (اختياري) | تمارين بريد محلية؛ ويمكن للوحدتين 10 و11 استخدام حزم أدلة `.eml` منقحة عند غياب Mailpit | 04، 10، 11 |

## مناطق الشبكة المخططة

| المنطقة | الشبكة الفرعية | عبء العمل الرئيسي |
|---|---|---|
| الإدارة | `10.0.10.0/24` | إدارة مضبوطة |
| SOC | `10.0.30.0/24` | Splunk Enterprise ومجمّعات البيانات |
| DMZ | `10.0.20.0/24` | خادم ويب Ubuntu |
| الأجهزة الطرفية | `10.0.40.0/24` | Windows مع Sysmon |
| Kali | `10.0.90.0/24` | Kali Linux |

هذه نطاقات مقترحة. على الطلاب التحقق من عدم تداخلها مع الشبكة المحلية الفعلية أو VPN أو Docker أو شبكات VMware القائمة. راجع `lab-environment/network/addressing-plan.md`.

## مسارات القياس المنطقية

- Windows/Sysmon ← مسار جمع مدعوم ← Splunk Enterprise.
- أحداث جدار pfSense النارية ← تسجيل بعيد أو مجمّع معدّ ← Splunk Enterprise.
- تنبيهات Suricata من pfSense ← تصدير أو مجمّع مختبر ومتوافق مع الحزمة ← Splunk Enterprise.
- سجلات ويب Ubuntu ← مسار جمع مدعوم ← Splunk Enterprise.
- نشاط Kali ← قياس pfSense/Suricata وقياس الوجهة.

يجب توثيق أساليب الجمع والمنافذ والفهارس وأنواع المصادر والتحليل والتحقق منها. راجع `lab-environment/deployment/telemetry-pipeline.md`.

## تبعيات الوحدات

تتضمن الوحدة 10 صراحةً عنصر دليل بريد من الوحدة 04. يظل Mailpit اختيارياً؛ ويُقبل بدلاً منه عنصر `.eml` منقح وموسوم بمصدره. تستخدم الوحدة 11 مصادر الأدلة المتضمنة في حزمة الحالة المسندة إليها.

| الوحدة | الحد الأدنى من القدرات |
|---|---|
| 01 | لا تتطلب مختبراً منشوراً |
| 02 | VMware وpfSense وSplunk Enterprise وشبكة مقسمة |
| 03 | Windows/Sysmon وجمع الأحداث وSplunk |
| 04 | Mailpit أو عينات بريد آمنة |
| 05 | Kali والتقاط الحزم وتحليلها وpfSense وSplunk |
| 06 | Suricata المدمج في pfSense وجمع الأحداث وSplunk |
| 07 | خادم ويب Ubuntu والسجلات وKali وSplunk |
| 08 | أدلة من الوحدات السابقة ذات الصلة وقوالب الحوادث |
| 09 | محاكاة معتمدة وقياس قيد الاختبار وSplunk |
| 10 | قياس متكامل للأجهزة الطرفية والشبكة وIDS والويب وSIEM |
| 11 | بيئة متكاملة وأدلة المشروع الختامي |

## بوابات التحقق

تحقق من إصدارات الآلات الافتراضية وعزل الشبكة والمسارات المقصودة وإنشاء الأحداث وإدخالها والطوابع الزمنية واستخراج الحقول وسير عمل الطالب والتنظيف وإعادة الضبط. سجّل الأدلة والانحرافات. تصف هذه الخريطة التبعيات المخططة فقط.
