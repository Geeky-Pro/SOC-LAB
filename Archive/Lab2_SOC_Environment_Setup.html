◆ STEP 1: NETWORK VISIBILITY

Step 1: Installing Wireshark & Npcap Driver

Wireshark is the world's foremost network protocol analyzer. It allows us to see network traffic at microscopic detail:

1

Download Installer

Navigate to wireshark.org/download.html and download the Windows Installer (64-bit).

2

Component Selection

Keep all default tools selected: Wireshark, TShark, Plugins/Extensions, and File Type associations.

3

Install Npcap

Crucial Step! Check "Install Npcap". In the Npcap wizard, check:
"Support raw 802.11 traffic" and "Restrict Npcap driver's access to Administrators only".

4

Complete & Reboot

Finish installation. If prompted by Npcap, reboot or restart network services to bind the driver.

◆ VERIFICATION & TESTING

Verifying Wireshark Functionality

Verify that your network interface is correctly capturing packets and responding to display filters:

1. Select Active Adapter

Launch Wireshark. Look for the adapter with active traffic sparklines (usually Wi-Fi or Ethernet). Double-click to begin capturing.

2. Generate Test Traffic

Open your web browser and navigate to example.com or ping a public DNS server from your terminal:
ping 8.8.8.8.

Testing Core Display Filters in the Filter Bar:

Wireshark Display Filter Testing
# Filter 1: Show only DNS queries and responses dns # Filter 2: Show only web HTTP requests http.request.method == "GET" || http.request.method == "POST" # Filter 3: Show only TCP SYN packets (Connection Initiation) tcp.flags.syn == 1 && tcp.flags.ack == 0
◆ STEP 2: ENDPOINT VISIBILITY

Step 2: Deploying the Sysinternals Suite

The Sysinternals Suite is the gold standard toolkit for Windows internals, process analysis, and forensic troubleshooting:

1

Download Suite ZIP

Visit learn.microsoft.com/sysinternals and download SysinternalsSuite.zip (~50 MB).

2

Extract to Dedicated Folder

Create a dedicated folder: C:\Tools\Sysinternals and extract all contents there.

3

Add to System PATH

Add C:\Tools\Sysinternals to your Windows Environment System PATH variable for instant terminal access.

4

Accept EULA Script

Run from admin terminal to suppress prompts:
reg add HKCU\Software\Sysinternals /v EulaAccepted /t REG_DWORD /d 1 /f

◆ HOST INSPECTION SETUP

Configuring Process Explorer with VirusTotal

Transform Process Explorer from a basic task manager into a live malware hunting console:

1. Run as Administrator

Right-click procexp64.exe and select "Run as administrator". Admin privileges are mandatory to view system-level services and handle tables.

2. Enable VirusTotal.com Integration

Click Options -> VirusTotal.com -> Check VirusTotal.com. Accept terms. Process Explorer will hash every running binary and query VirusTotal!

🎯 What to Look for in the VirusTotal Column

0 / 75 (Green): Clean, verified executable known by all commercial antivirus engines.
N / 75 (Red, e.g. 48/75): Flagged as malicious trojan/ransomware by 48 vendors — investigate immediately!
Unknown / Hash not found: Unseen custom binary or newly compiled payload — high suspicion!

◆ HOST INSPECTION SETUP

Configuring Autoruns for Persistence Hunting

Autoruns shows every program, DLL, driver, and task configured to execute automatically at boot or user logon:

1. Run Autoruns64 as Administrator

Launch Autoruns64.exe with Administrator privileges so it can inspect machine-wide keys in HKLM and hidden drivers.

2. The Golden Filter Setting

In the top menu, click Options -> Scan Options. Check:
✅ Hide Microsoft Entries
✅ Hide Windows Entries
✅ Verify Code Signatures

⚡ The Magic of Filtering OS Noise

By hiding Microsoft and Windows entries, you reduce the list from 2,000+ entries down to ~20 third-party items! Any persistence mechanism installed by an attacker (malicious service, Run key, or scheduled task) will stand out immediately in bold red/yellow!

◆ HANDS-ON SPL QUERYING

Executing Your First Search Processing Language (SPL) Queries

Go to Search & Reporting. Set time range to "All time" or "Last 24 hours" and run these fundamental queries:

Query 1: Find All Successful Logons (Event ID 4624)

SPL Query 1 — Successful Logons by User
source="WinEventLog:Security" EventCode=4624 | stats count by user, Logon_Type | sort - count

Query 2: Hunt for Failed Logon Attempts (Event ID 4625)

SPL Query 2 — Failed Logons Triage
source="WinEventLog:Security" EventCode=4625 | table _time, user, Sub_Status, Source_Network_Address | sort - _time

Query 3: Detect Newly Created Processes (Event ID 4688)

SPL Query 3 — Process Creation Hunting
source="WinEventLog:Security" EventCode=4688 | stats count by New_Process_Name | sort - count
◆ STEP 4: TRIAGE UTILITIES

Step 4: Setting up CyberChef & Phishing Analysis Utilities

A SOC analyst frequently analyzes suspicious strings, encoded payloads, and phishing links. We use dedicated offline utilities:

CyberChef (GCHQ)

The "Cyber Swiss Army Knife". Download the offline standalone bundle from github.com/gchq/CyberChef. Runs 100% locally in your browser.

Defang Utilities

Converts dangerous live URLs into safe non-clickable text for ticketing systems:
http://evil.com ➡️ hxxp://evil[.]com.

Header Analyzers

Save bookmarks for: Microsoft Message Header Analyzer (mha.azurewebsites.net) and MXToolbox for SPF/DKIM verification.

🔒 The Cardinal Rule of Phishing Triage

Never open live malicious URLs in your personal browser! Always defang URLs before pasting into ticketing tools, and detonate or analyze samples inside sandboxes or offline decoders like CyberChef.
