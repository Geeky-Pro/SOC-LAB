# Archive

This directory preserves historical SOC-LAB materials that were moved here before the repository architecture redesign.

## Rules

- Treat archived content as historical source material, not automatically approved current curriculum.
- Do not delete, rename, or rewrite archived files as part of routine curriculum development.
- Review a source before reusing it; verify technical accuracy, tool versions, safety, instructional fit, licensing, and duplication.
- When content is adopted into the new architecture, create a maintained version in the appropriate module or shared directory and record its provenance where useful.
- Keep the archive intact unless the Project Owner explicitly approves a separate archival cleanup.

The archive may contain outdated configurations, duplicate language variants, old lesson numbering, or references to tools that are no longer part of the current lab baseline.
