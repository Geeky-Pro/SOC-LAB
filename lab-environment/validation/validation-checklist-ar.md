# قائمة التحقق من المختبر

> الحالة: قالب قائمة تحقق. لا يُعتمد أي بند حتى تجمع أدلة.

## المضيف ومراقب الآلات الافتراضية

- [ ] يعمل VMware والافتراضية العتادية.
- [ ] تكفي موارد المضيف لتشغيل الآلات المطلوبة بالتزامن.
- [ ] توجد أقراص الآلات ولقطاتها خارج Git.
- [ ] لا تتداخل الشبكات الفرعية مع LAN المضيف أو VPN أو Docker أو VMnet قائمة.

## عزل الشبكة

- [ ] تستخدم WAN في pfSense وصلة NAT المقصودة.
- [ ] ترتبط VMnet الداخلية بمناطقها الصحيحة.
- [ ] Kali غير مجسور ولا يستطيع الوصول إلى LAN الفعلية.
- [ ] تعبر الحركة بين المناطق pfSense.
- [ ] لا يتعارض DHCP وDNS وNTP والعنونة الثابتة.

## الجدار الناري وSuricata

- [ ] وصول الإدارة مقيد.
- [ ] تم التحقق من المنع الافتراضي بين المناطق.
- [ ] قواعد السماح المطلوبة محددة النطاق ومسجلة.
- [ ] حزمة Suricata مطابقة لإصدار pfSense.
- [ ] أُنشئ تنبيه اختبار آمن على الواجهة المقصودة.
- [ ] يصل قياس الجدار الناري وIDS إلى المجمّع المعد.

## الطرفيات والويب وSIEM

- [ ] عنوان Windows والبوابة والوقت وإعداد Sysmon صحيحة.
- [ ] يمكن البحث عن حدث Windows معروف في Splunk.
- [ ] لا يمكن الوصول إلى خدمة Ubuntu إلا من المصادر المقصودة.
- [ ] يمكن البحث عن حدث ويب معروف.
- [ ] لا يمكن الوصول إلى Splunk إلا من مصادر الإدارة/الجمع المعتمدة.
- [ ] الفهارس وأنواع المصادر والمضيف والطوابع الزمنية والحقول صحيحة.
- [ ] يظل حجم الأحداث واستخدام القرص ضمن الميزانية.

## التدريس والتعافي

- [ ] خطوات الطالب قابلة لإعادة الإنتاج.
- [ ] توجد لقطات خط أساس نظيف.
- [ ] يمكن إزالة القواعد المؤقتة وعناصر الاختبار.
- [ ] تعيد عملية الضبط الحالة النظيفة المقصودة.
- [ ] الأدلة منقحة ولا تتضمن أسراراً أو بيانات شخصية.
