# جرد الآلات الافتراضية

> الحالة: جرد خط الأساس. لا تثبت إصدارات البرامج إلا بعد اختبار التوافق.

| الآلة الافتراضية | الدور | الشبكة | البرامج | مطلوبة |
|---|---|---|---|---|
| pfSense | التوجيه والجدار الناري وSuricata | WAN وخمس مناطق داخلية | pfSense وحزمة Suricata متوافقة | نعم |
| خادم Splunk | SIEM | SOC | Splunk Enterprise | نعم |
| طرفية Windows | قياس الطرفيات عن بُعد | الطرفيات | Windows 10/11 وSysmon ومكون جمع مدعوم | نعم |
| خادم Ubuntu | عبء عمل ويب DMZ | DMZ | Ubuntu Server وخدمة ويب ومجمّع سجلات مدعوم | نعم |

| Mailpit | التقاط بريد محلي | مقطع بريد معزول أو مرفق موثق | Mailpit | اختياري |

## pfSense

استخدم ست بطاقات شبكة افتراضية: WAN إضافةً إلى MGMT وSOC وDMZ وEndpoint وKali. ثبّت Suricata كحزمة pfSense لا كآلة افتراضية منفصلة. تحقق من توافق الحزمة مع إصدار pfSense المختار. قيّد وصول الإدارة وصدّر نسخة احتياطية للإعداد.

## Splunk Enterprise

ضعه في منطقة SOC. استخدم Splunk Enterprise فقط؛ ولا يلزم Enterprise Security. أعد الإدارة الآمنة ومزامنة الوقت والتخزين والفهارس والاحتفاظ. قيّد واجهات الاستقبال والإدارة بالمصادر المعتمدة. أبقِ مواد الترخيص خارج Git واتبع شروط الترخيص.

## Windows

استخدم إصدار Windows مدعوماً وإعداد Sysmon موثقاً. فعّل الأحداث ذات الصلة بالدروس فقط، واستخدم مكون جمع مدعوماً لإعادة توجيه القياس عبر مسار SOC. استخدم حسابات اصطناعية وبيانات غير حساسة.

## Ubuntu

ضعه في DMZ فقط. شغّل خدمة ويب دنيا وأنشئ سجلات وصول وأخطاء سليمة، وأعد توجيه السجلات المطلوبة عبر المسار المعتمد. قيّد SSH والإدارة.

## Kali

اربطه بـ VMnet الخاصة بـ Kali فقط. استخدم اللقطات وأهداف المختبر المحددة صراحةً. لا تمكّن الشبكة المجسورة مطلقاً.

## بيان الآلات الافتراضية

لكل بناء صفي، سجل إصدارات أنظمة التشغيل والتطبيقات والعتاد الافتراضي ومواءمة VMnet وصيغة الأقراص والبصمات واسم اللقطة وتاريخ التحقق. لا تودع أقراص الآلات الافتراضية.
