# فهرس مصادر القياس عن بُعد

> **الحالة:** فهرس أولي. لا تكون جاهزية المصدر متحققاً منها حتى تُفحص الأحداث والحقول الفعلية.

## حالات جاهزية المصدر

- `planned`: المصدر مقصود لكنه غير معد.
- `configured`: طُبقت إعدادات الجمع.
- `receiving`: الأحداث تصل.
- `parsed`: استُخرجت الحقول المطلوبة وفُحصت.
- `validated`: فُحصت أحداث اختبار تمثيلية وحالات إخفاق.
- `degraded`: المصدر موجود لكنه ناقص أو غير موثوق.
- `retired`: لم يعد مستخدماً.

## جرد المصادر الأولي

| المصدر | القياس المتوقع | نقل مرشح | الجاهزية |
|---|---|---|---|
| Windows مع Sysmon | أحداث العمليات والشبكة وتسجيل الدخول والملفات/السجل وفق الإعداد | مسار جمع Windows مدعوم إلى Splunk | لم يتم التحقق |
| pfSense | أحداث الجدار الناري وأحداث نظام مختارة | تسجيل بعيد/مجمّع معد | لم يتم التحقق |
| Suricata على pfSense | التنبيهات وبيانات وصفية مختارة | تصدير/مجمّع متوافق مع الحزمة | لم يتم التحقق |
| خادم ويب Ubuntu | سجلات الوصول والأخطاء | مسار جمع Linux مدعوم | لم يتم التحقق |
| نشاط Kali | النشاط المرئي في سجلات الحساس/الهدف وقياس الحزم | ملاحظة غير مباشرة عبر حساسات المختبر | لم يتم التحقق |

## السجل المطلوب لكل مصدر

سجل ما يلي:

- اسم المصدر ودور المضيف وإصدار نظام التشغيل/المنتج والمالك؛
- وكيل الجمع/المحوّل وإصداره ومرجع إعداده؛
- الفهرس ونوع المصدر وهوية المضيف وحقل وقت الحدث؛
- الحقول المتوقعة مع قيم نموذجية من أحداث اختبار حقيقية منقحة؛
- حجم الأحداث ومتطلبات الاحتفاظ وتأخيرات الجمع المعروفة؛
- مسار الشبكة وتبعيات الجدار الناري والمنافذ المسموح بها؛
- فحص الصحة وأعراض الإخفاق وإجراء الاستعادة؛
- قيود جودة البيانات واعتبارات الخصوصية؛
- آخر حدث مرصود وتاريخ التحقق ومرجع الدليل.

## قيود مهمة

لا تفترض المنافذ أو أنواع المصادر أو الفهارس أو استخراج الحقول أو سلوك تسليم Suricata EVE بدقة حتى تُختبر إصدارات المنتج وطريقة الجمع المختارة. استخدم خط أنابيب قياس المختبر مرجعاً معمارياً. يجب التحقيق في غياب الأحداث بوصفه فجوة جمع أو رؤية، لا تفسيره دليلاً على عدم وقوع السلوك.
