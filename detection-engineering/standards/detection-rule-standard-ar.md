# معيار قاعدة الكشف

> **الحالة:** معيار مسودة.

## 1. الغرض والنطاق

الكشف تحليل موثق يحدد سلوكاً قابلاً للملاحظة ومحدداً انطلاقاً من قياس عن بُعد معين. وليس مجرد بحث يعيد أحداثاً. يجب أن يدعم كل كشف قراراً للمحلل أو هدف تعلم قابلاً للقياس.

## 2. المواصفات المطلوبة

يجب أن تتضمن كل مواصفة كشف:

| الحقل | المتطلب |
|---|---|
| معرّف الكشف | معرّف فريد ثابت، مثل `SOC-DET-001` |
| الاسم/الملخص | عنوان واضح يركز على السلوك ووصف موجز |
| الحالة/الإصدار | حالة دورة الحياة والمراجعة الدلالية |
| الهدف | قدرة المحلل أو السؤال الأمني المدعوم |
| السلوك | السلوك القابل للملاحظة؛ تجنب ادعاءات النية غير المسندة |
| تبعيات البيانات | المصدر والفهرس ونوع المصدر والحقول المطلوبة ومتطلبات الجمع السابقة |
| SPL | استعلام كامل مع النافذة الزمنية وافتراضات الحقول |
| النتيجة المتوقعة | ما ينبغي أن ينتجه الاختبار الإيجابي؛ لا تختلق أحداثاً نموذجية |
| الإيجابيات الكاذبة | الأسباب السليمة المعروفة وفحوص السياق |
| الفرز | خطوات المحلل المرتبة والتنقل بين الأدلة وما يجب حفظه |
| مبرر الشدة | عوامل الأثر والثقة؛ اشرحها بدلاً من إسنادها اعتباطاً |
| مواءمة ATT&CK | معرّف التقنية واسمها ودليل السلوك وإصدار ATT&CK؛ احذفها إن لم تسندها الأدلة |
| حالات الاختبار | اختبارات إيجابية وسلبية وحالات حدية وجودة بيانات بحسب الحاجة |
| الضبط | الاستثناءات/الكبت مع المبرر وتاريخ الانتهاء أو خطة المراجعة |
| القيود | فجوات الرؤية وطرق التجاوز والتبعيات والنقاط العمياء المعروفة |
| المراجع | مصادر موثوقة ووثائق المصدر الداخلية |
| الملكية | المؤلف والمراجع والمجيز وتاريخ آخر مراجعة |

## 3. مبادئ جودة الكشف

- اكشف السلوك، لا اسم ملف أو أداة أو مؤشر منفرداً، إلا إذا كان المؤشر ذاته هو الهدف الصريح.
- فضّل إشارات متعددة ذات صلة وإثراء السياق عندما يدعم القياس ذلك.
- ميّز الوقائع المرصودة عن فرضيات المحلل.
- تجنب الافتراضات الهشة بشأن أسماء المضيفين أو المستخدمين أو المسارات أو النصوص المترجمة أو ترتيب الأحداث.
- اذكر النافذة الزمنية وافتراضات حقل وقت الحدث.
- تجنب أحرف البدل الواسعة والأوامر المكلفة غير الضرورية؛ واختبر أداء البحث على بيانات تمثيلية.
- لا تخفِ عدم اليقين باستخدام أسماء أو أوصاف تنبيه مبالغ في قوتها.
- وثّق ما إذا كان المنطق قائماً على حدث أو حد أو تسلسل أو ترابط.

## 4. معايير القبول

لا ينتقل الكشف إلى `in-review` إلا بعد اكتمال الحقول المطلوبة والتحقق من صياغة SPL مقابل نموذج البيانات المعلن. ولا ينتقل إلى `implemented` إلا بعد تثبيته في البيئة المقصودة. ولا ينتقل إلى `validated` إلا بعد تسجيل أدلة قابلة لإعادة الإنتاج لاختبارات إيجابية وسلبية ذات صلة، وإصدارات مصدر البيانات والنطاق الزمني والنتيجة.

لا تثبت المراجعة الثابتة تحقق وقت التشغيل. ولا يثبت اختبار إيجابي واحد تغطية واسعة. يجب أن يذكر كل بيان تحقق نطاقه.

## 5. السلامة والخصوصية

استخدم أحداث اختبار سليمة وهويات اصطناعية. لا تدرج بيانات اعتماد حقيقية أو بيانات شخصية أو برمجيات خبيثة أو قياساً إنتاجياً حساساً. يجب أن تتبع أي محاكاة سياسة سلامة المختبر المعزول وأن تحدد النطاق والتنظيف صراحةً.

## 6. ضبط التغييرات

تتطلب التغييرات في SPL أو الحقول المطلوبة أو الحدود أو الاستثناءات أو تبعيات البيانات أو الشدة أو مواءمة ATT&CK زيادة رقم الإصدار وملاحظة تشرح الأثر. أعد تشغيل حالات الاختبار المتأثرة بعد التغييرات الجوهرية.
