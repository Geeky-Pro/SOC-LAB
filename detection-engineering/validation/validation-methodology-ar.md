# منهجية التحقق من الكشف

> **الحالة:** منهجية مسودة؛ لم يتم التحقق من أي كشف باستخدام هذه الوثيقة.

## 1. هدف التحقق

تحديد ما إذا كان الكشف يحدد السلوك الموثق ضمن مجموعة محددة من ظروف المختبر، مع تجنب النشاط السليم المتوقع وتحديد النقاط العمياء في جودة البيانات.

## 2. أبعاد الاختبار

اختر الاختبارات الملائمة لكل كشف:

| نوع الاختبار | السؤال |
|---|---|
| إيجابي | هل ينتج السلوك الموثق نتيجة الكشف المتوقعة؟ |
| سلبي | هل يتجنب النشاط السليم التمثيلي إطلاق التنبيه؟ |
| حدودي | ماذا يحدث عند حدود العتبة والنافذة الزمنية والتسلسل؟ |
| جودة البيانات | ماذا يحدث عندما تكون الحقول خالية أو متأخرة أو مكررة أو مشوهة؟ |
| التغطية | أي تنويعات أو مسارات مرئية وأيها غير مرئي؟ |
| الأداء | هل يكتمل البحث ضمن حدود مقبولة للموارد والوقت؟ |
| التعافي | هل يستأنف الكشف عمله على نحو صحيح بعد انقطاع المصدر أو إصلاح الإعداد؟ |

## 3. إجراء اختبار آمن

1. أكد نطاق المختبر المعزول والهدف والتصريح واللقطة وخطة التنظيف.
2. تحقق من سلامة المصدر ومزامنة الوقت.
3. سجل إصدارات البناء ومراجعة الكشف وSPL والفهارس وأنواع المصادر ونافذة البحث.
4. أنشئ حدث اختبار موثقاً وسليماً أو استخدم عينة اختبار آمنة.
5. احفظ دليل الحدث المصدر ومخرجات البحث الدقيقة.
6. نفذ اختبارات سلبية وحدية ذات صلة.
7. سجل النتيجة المرصودة مقابل المتوقعة.
8. لا تضبط المنطق إلا بمبرر موثق؛ ثم أعد الاختبارات المتأثرة.
9. أزل العناصر المؤقتة وأعد خط الأساس عند الحاجة.

لا تستخدم برمجيات خبيثة حية أو أهدافاً خارجية غير معتمدة للتحقق الاعتيادي. اتبع سياسة السلامة الخاصة بالمستودع وحدود التصريح الخاصة بالتمرين.

## 4. حزمة الأدلة

ينبغي أن يتضمن سجل التحقق:

- معرّف الكشف وإصداره؛
- معرّف بناء المختبر وإصدارات مكوناته؛
- معرّفات حالات الاختبار ووقت الاختبار والمشغل والنطاق؛
- مراجع أحداث المصدر أو مقتطفات أحداث منقحة؛
- SPL الدقيق والنطاق الزمني للبحث؛
- النتائج المتوقعة والمرصودة؛
- لقطات شاشة أو صادرات بعد إزالة المعلومات الحساسة؛
- ملاحظات الإيجابيات الكاذبة والنقاط العمياء؛
- ملاحظات زمن البحث والموارد عند الصلة؛
- النتيجة النهائية والقيود.

## 5. مفردات النتائج

- `PASS`: اجتازت جميع الاختبارات المطلوبة للنطاق المعلن.
- `PASS WITH NOTES`: اجتازت الاختبارات المطلوبة مع قيود موثقة.
- `FAIL`: أخفق اختبار مطلوب واحد أو أكثر في تحقيق التوقعات.
- `BLOCKED`: لم تتوفر المتطلبات أو بيانات القياس اللازمة.
- `NOT RUN`: لا يوجد دليل تنفيذ.

## 6. ادعاءات التغطية

استخدم صياغة محدودة مثل «تم التحقق على إعداد Sysmon X في بناء المختبر Y باستخدام حالات الاختبار A–C». لا تدّعِ تغطية ATT&CK كاملة أو جاهزية إنتاجية أو كشفاً شاملاً بناءً على اختبار مختبر صغير.
